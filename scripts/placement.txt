# putc.c / getc.c family — keep them.  putc.h / getc.h pull in
# pthread_impl.h for the per-FILE lock dance; v0.8 supplies an
# OS-owned pthread_impl.h shim at userland/libc/include/, symlinked
# into core/userland/libc/src/internal/ by the libc Makefile.  In
# single-threaded mode (libc.threaded==0, no pthread_create stub
# flipping it) the locked path is reachable at link time but never
# at runtime — do_putc() short-circuits via `f->lock == -1`.
# See userland/libc/include/pthread_impl.h for the lifetime story.
