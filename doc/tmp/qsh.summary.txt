qsh compile-attempt — v0.6.2 summary
=====================================

Source pulled from QRV-OS/userland/sh (mksh-derived QNX shell):
  29 .c files, 15 .h files, ~26k LoC

Compiled against musl + libqsoe (TM_CFLAGS, -isystem musl, -I qsh/include,
-I qsh/gen) with all warnings demoted.

Result: 22 of 29 .c files compile cleanly. 7 fail. The 7 failures
fall into four categories:

  1. Missing QRV proprietary header  (edit.c)
       userland/qsh/edit.c:33:10: fatal error: sys/qrv_core.h:
         No such file or directory
     edit.c includes <sys/qrv_core.h> for QRV's non-POSIX termios
     extensions. QSOE has neither this header nor the underlying
     calls.

  2. sh.h needs a missing typedef  (histrap.c, shf.c)
       userland/qsh/include/sh.h:190:40: error: expected declaration
         specifiers or '...' before '(' token
       userland/qsh/include/sh.h:191:35: error: expected identifier
         or '(' before 'const'
       userland/qsh/include/sh.h:252:35: error: expected identifier
         or '(' before 'const'
     A macro / typedef from <sys/qrv_core.h> (or a transitively-
     included QRV header) is needed before sh.h's declarations make
     grammatical sense.

  3. Missing platform-symbol defines  (histrap.c, tempfile.c)
       histrap.c: signames.inc references SIGEMT (BSD-only signal
         not in musl's signal.h)
       tempfile.c: references MKSH_DEFAULT_TMPDIR (autogenerated in
         QRV's build; absent here)

  4. Inter-file declaration ordering  (eval.c, jobs.c, misc.c)
       eval.c: 'homedirs' undeclared (declared in something we don't
         pull in)
       jobs.c, misc.c: implicit declaration of j_change (defined in
         jobs.c but referenced from misc.c before its prototype)
     Likely fixable with a small header tweak or by enabling a
     config option in QRV's Makefile.

Link-time undefined-after-libc.a count: 84 distinct symbols.
Almost all are mksh-internal names defined IN one of the 7 files
that failed to compile (j_init, j_kill, j_change, exchild, evalstr,
gmatchx, ksh_getopt*, etc.). Once the 7 fail-to-compile files
compile, most of these resolve.

Genuine missing libc/system primitives (NOT mksh-internal):
  _longjmp       — BSD-style longjmp; musl provides longjmp/siglongjmp
                   under the unprefixed names
  ...and a handful similar (search build/qsh.symbols.txt.objs.txt
  for the full alphabetised list).

Files for inspection:
  build/qsh.log                     — full compile log with per-file
                                       headers
  build/qsh.symbols.txt             — raw ld --warn-unresolved-symbols
                                       output
  build/qsh.symbols.txt.objs.txt    — per-object nm -u set (sorted
                                       unique)

Recommendation for v0.6.x / v0.7+:
  - Resolve the QRV-header dependency (port what's needed of
    sys/qrv_core.h, or write QSOE equivalents).
  - The 84 unresolved symbols collapse to ~5-10 real missing libc
    primitives once the 7 failed files build.
  - mksh's full feature set (job control, pipes, dup2, termios)
    needs corresponding QSOE-side support — separate effort per
    primitive.
